# english-sentence-analyzer

英语句子分析工具：输入英文句子，输出结构化的分析结果，面向中文使用者。

## 长句分析

核心场景是长句分析，分三个大步骤：

1. **拆分单句**：按主谓结构把长句拆成主谓齐全、可独立分析的单句单元，嵌套关系只登记不拆散，供整合时挂回原位。
2. **分析单句**：对每个单句单元执行单句分析——句子结构、成分划分、语法点、词汇与中译。这一步是单句粒度的基础能力。
3. **整合单句**：把各单句的分析装配回整体——恢复连接词与逻辑关系，衔接跨单元的指代与省略，输出贯通的整句解释与整体翻译。
